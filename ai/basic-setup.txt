BASIC SETUP
===========

CRITICAL: This is a Svelte 5 component using runes
- Package: @keenmate/svelte-treeview v5.0.0-rc13
- Requires Svelte 5.0.0 or higher (peer: svelte ^5.0.0)
- Uses $state, $derived, $effect runes
- NOT compatible with Svelte 4 or earlier
- Works with SvelteKit, Vite, or any Svelte 5 setup
- Canvas rendering lives in a separate package (@keenmate/svelte-treeview-canvas)

INSTALLATION
------------
npm install @keenmate/svelte-treeview

# Or yarn
yarn add @keenmate/svelte-treeview

# Or pnpm
pnpm add @keenmate/svelte-treeview

IMPORT STYLES
-------------
The component requires CSS to display correctly:

// In your main.js/main.ts or +layout.svelte
import '@keenmate/svelte-treeview/styles.css';

MINIMAL EXAMPLE
---------------
<script lang="ts">
  import { Tree } from '@keenmate/svelte-treeview';

  const data = [
    { id: '1', path: '1', name: 'Documents' },
    { id: '1.1', path: '1.1', name: 'Projects' },
    { id: '1.1.1', path: '1.1.1', name: 'Project A' },
    { id: '2', path: '2', name: 'Pictures' }
  ];
</script>

<Tree
  nodes={data}
  idMember="id"
  pathMember="path"
  displayValueMember="name"
/>

REQUIRED PROPS
--------------
These props are required for the tree to work:

| Prop | Type | Description |
|------|------|-------------|
| data | T[] | Array of data objects |
| idMember | string | Property name for unique ID |
| pathMember | string | Property name for hierarchical path |

RECOMMENDED PROPS
-----------------
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| displayValueMember | string | null | Property for display text |
| sortCallback | function | built-in | Custom sort function |
| expandLevel | number | 2 | Auto-expand nodes to this depth |
| treeId | string | auto | Stable id (needed for cross-tree clipboard/drag) |
| clickBehavior | string | 'expand-and-focus' | 'select' \| 'expand' \| 'expand-and-focus' |
| isCheckboxesShown | boolean | false | Render a selection checkbox per node |
| checkboxMode | string | 'independent' | 'independent' \| 'cascade' |

PATH STRUCTURE
--------------
CRITICAL: Data must use path-based hierarchy

The path defines the tree structure:
- Root level: "1", "2", "3"
- Second level: "1.1", "1.2", "2.1"
- Third level: "1.1.1", "1.2.1"

Parent path is derived from child path:
- "1.2.3" → parent is "1.2"
- "1.2" → parent is "1"
- "1" → no parent (root)

Custom separators:
<Tree treePathSeparator="/" ... />
// Paths: "1/2/3", "files/docs/readme"

BINDING FOCUSED NODE
--------------------
<script>
  let focusedNode = $state(null);
</script>

<Tree
  nodes={data}
  idMember="id"
  pathMember="path"
  bind:focusedNode
/>

{#if focusedNode}
  <p>Focused: {focusedNode.data.name}</p>
{/if}

Other bindable selection state:
- bind:focusedNode        // single focused node (click / arrow keys)
- bind:selectedPaths   // Set<string> — UI multi-select (Ctrl/Shift+click)
- bind:checkedPaths      // Set<string> — checkbox data state

BINDING SEARCH TEXT
-------------------
<script>
  let searchTerm = $state('');
</script>

<input bind:value={searchTerm} placeholder="Search..." />

<Tree
  nodes={data}
  idMember="id"
  pathMember="path"
  bind:searchTerm
  shouldUseInternalSearchIndex={true}
  searchValueMember="name"
/>

CUSTOM NODE TEMPLATE
--------------------
<Tree
  nodes={data}
  idMember="id"
  pathMember="path"
>
  {#snippet nodeTemplate(node)}
    <div class="custom-node">
      <span class="icon">{node.data.icon}</span>
      <span class="name">{node.data.name}</span>
      {#if node.data.count}
        <span class="badge">{node.data.count}</span>
      {/if}
    </div>
  {/snippet}
</Tree>

IMPORTANT: The snippet name is nodeTemplate (not nodeContent)

EXPAND/COLLAPSE CONTROL
-----------------------
Control initial expansion:

<Tree
  nodes={data}
  expandLevel={3}  <!-- Expand first 3 levels -->
/>

Programmatic control:

<script>
  let treeRef;
</script>

<Tree bind:this={treeRef} nodes={data} ... />

<button onclick={() => treeRef.expandAll()}>Expand All</button>
<button onclick={() => treeRef.collapseAll()}>Collapse All</button>
<button onclick={() => treeRef.expandNodes('1.2')}>Expand 1.2</button>
<button onclick={() => treeRef.toggleNodeExpanded('1.2')}>Toggle 1.2</button>
<!-- ExpandOptions { isExclusive?, isSilent? }: expandNodes('1.2', { isExclusive: true })
     collapses every other open branch; expandAll/collapseAll(paths?) — null = whole tree,
     paths = those nodes + all descendants -->

CLICK HANDLING
--------------
<Tree
  nodes={data}
  idMember="id"
  pathMember="path"
  onNodeClick={(ctx) => {
    console.log('Clicked:', ctx.node.data.name);
    console.log('Path:', ctx.path);
    // ctx is a NodeRef: { path, node, parent, siblings }
  }}
/>

All on* events are fire-and-forget and take ONE context object.

Click behavior (default 'expand-and-focus'):
<Tree clickBehavior="select" ... />
<!-- 'select' = click selects, dblclick expands -->
<!-- 'expand' = click expands only -->
<!-- 'expand-and-focus' = click focuses + expands -->

SCROLL TO NODE
--------------
<script>
  let treeRef;

  async function goToNode() {
    await treeRef.scrollToPath('1.2.3', {
      shouldExpandAncestors: true, // Expand parents first (default)
      shouldHighlight: true,       // Flash scrollHighlightClass (default false)
      behavior: 'smooth', block: 'center'   // native ScrollIntoViewOptions
    });
  }
</script>

<Tree bind:this={treeRef} nodes={data} ... />
<button onclick={goToNode}>Go to 1.2.3</button>

TREE STATISTICS
---------------
<script>
  let treeRef;

  function showStats() {
    const stats = treeRef.statistics;
    console.log('Total nodes:', stats.nodeCount);
    console.log('Max depth:', stats.maxLevel);
    console.log('Filtered:', stats.filteredNodeCount);

DEBUG LOGGING
-------------
No in-tree debug panel (shouldDisplayDebugInformation was removed).
Use the category loggers:

import { enableLogging, setCategoryLevel } from '@keenmate/svelte-treeview';
enableLogging();
setCategoryLevel('LTREE:DATA', 'debug');

EMPTY STATE
-----------
Custom message when tree is empty:

<Tree nodes={data} ...>
  {#snippet noData()}
    <div class="empty-state">
      <p>No items found</p>
      <button>Add First Item</button>
    </div>
  {/snippet}
</Tree>

The snippet name is noData (not noDataFound). Without a snippet the
labels prop supplies the text: labels.noData (default "No data") when the
tree has no nodes, labels.noResults (default "No results found") when the
search filter matched nothing. '' renders nothing.
<Tree nodes={data} labels={{ noData: 'Nothing here yet' }} />

LABELS (UI strings)
-------------------
labels?: Partial<TreeLabels> — merged per key over the English defaults:
  noData "No data" | noResults "No results found" | dropHere "Drop here"
  noDisplayValue "[N/A]" (node with no display value) | loading "Loading…"
'' = deliberately empty (render nothing); missing/undefined = default.
Text only (escaped by Svelte). Snippets noData / dropPlaceholder /
loadingPlaceholder still replace the markup.

LOADING STATE
-------------
Show a loading placeholder while data is being fetched:

<Tree nodes={data} isLoading={isLoading}>
  {#snippet loadingPlaceholder()}
    <div class="loading">Loading tree data...</div>
  {/snippet}
</Tree>

Overlay: role="status" + aria-label = labels.loading. Content precedence:
loadingPlaceholder snippet > page-wide window.components.renderLoaderCallback
(the KeenMate shared loader hook, ctx { component: 'svelte-treeview',
context: 'overlay', containerElement, element, label }, may return a cleanup)
> the default .stv-loader, drawn from --stv-loader-icon / -rotate / -duration /
-size (-> --base-loader-*); overlay size --stv-loader-overlay-size (size x 2),
per-node lazy-load toggle --stv-loader-inline-size (size x 0.75), colour
--stv-loader-color.

DROP PLACEHOLDER
----------------
Custom placeholder for empty trees that accept drops:

<Tree nodes={data} dragDropMode="both">
  {#snippet dropPlaceholder()}
    <div class="drop-here">Drop items here to start</div>
  {/snippet}
</Tree>

COMMON SETUP PATTERNS
---------------------
File explorer:
<Tree
  nodes={data}
  idMember="id"
  pathMember="path"
  displayValueMember="name"
  expandLevel={1}
  treePathSeparator="/"
/>

Organization tree:
<Tree
  nodes={data}
  idMember="employeeId"
  pathMember="orgPath"
  displayValueMember="fullName"
  expandLevel={3}
/>

With search and drag-drop:
<Tree
  nodes={data}
  idMember="id"
  pathMember="path"
  bind:searchTerm
  shouldUseInternalSearchIndex={true}
  searchValueMember="name"
  dragDropMode="both"
  onNodeDrop={handleDrop}
/>

onNodeDrop receives a single NodeDropContext object:
<script>
  function handleDrop(ctx) {
    // ctx = { source, target, dragged, dropped, position, operation, event }
    // source/target/dragged/dropped are NodeRef(s); target null = root/empty
    console.log(ctx.operation, ctx.position, ctx.target?.path);
  }
</script>

CRITICAL REMINDERS
------------------
✅ Import styles (pure CSS: '@keenmate/svelte-treeview/styles.css')
✅ Use Svelte 5.0.0 or higher
✅ Use path-based hierarchical data
✅ Set idMember and pathMember
✅ Use $state.raw() for large datasets (1000+ items)

❌ Don't use with Svelte 4 or earlier
❌ Don't forget to import styles
❌ Don't use non-path-based data structures
❌ Don't use $state() for large datasets (causes slowdown)
