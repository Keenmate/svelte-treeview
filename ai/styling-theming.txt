STYLING AND THEMING
===================

CRITICAL: Styles must be imported separately
- Component has no embedded styles
- Import the bundled CSS once at app level
- Extensive CSS variables for theming
- Styling is PURE CSS (bundled via lightningcss to dist/styles.css) — there is NO SCSS/SASS

IMPORT STYLES
-------------
// Bundled CSS (all partials merged)
import '@keenmate/svelte-treeview/styles.css';

// Or an individual partial (rarely needed; the bundle is preferred)
import '@keenmate/svelte-treeview/styles/main.css';

CSS VARIABLES
-------------
Override in your CSS:

:root {
  /* Base sizing unit — scale all dimensions with one knob */
  --stv-rem: 10px;

  /* Indentation */
  --stv-indent-size: calc(0.8 * var(--stv-rem));

  /* Colors — tints derived automatically via color-mix() */
  --stv-accent-color: #0d6efd;
  --stv-success-color: #198754;
  --stv-danger-color: #dc3545;
  --stv-elevated-bg: #f8f9fa;
  --stv-border-color: #dee2e6;
  --stv-text-color-1: #212529;

  /* Touch ghost */
  --stv-touch-ghost-bg: rgba(59, 130, 246, 0.9);
  --stv-touch-ghost-text-color: white;
}

--base-* TOKEN INTEGRATION
--------------------------
Every --stv-* variable chains through a --base-* token shared with other
@keenmate/* web components, then falls back to a hardcoded default:

  --stv-accent-color: var(--base-primary-color, #3b82f6);

Set --base-* once at :root and every KM component picks it up automatically:

:root {
  --base-primary-color: #6366f1;
  --base-font-family: 'Inter', system-ui, sans-serif;
  --base-border-color: #e5e7eb;
  --base-border-radius-sm: 0.6;   /* unitless multiplier × --stv-rem */
  --base-text-color-1: #111827;
  --base-text-color-3: #6b7280;
  --base-hover-bg: #f3f4f6;
}

Tree-specific --stv-* overrides take precedence over --base-* tokens, so
you can theme a single tree without affecting other components.

The --stv-* names are the same list as @keenmate/web-treeview's --wtv-* (only
the prefix differs).

MOTION
------
Only the contract's four speeds + easings; no prop turns animations on/off:
  --stv-transition-fast | -normal | -medium | -slow
      = var(--base-duration-*, 0.1s | 0.15s | 0.25s | 0.3s)
  --stv-ease-standard | -out | -in = var(--base-ease-*)
  --stv-spinner-duration: 0.8s   (spinner loop; keeps turning under reduced motion)
Motion off (this tree):  .stv__container { --stv-transition-normal: 0s; ... all four }
Motion off (page-wide):  :root { --base-duration-fast: 0s; ... all four }
prefers-reduced-motion: reduce -> the four --stv-transition-* are 0s.
Disabled dimming: --stv-disabled-opacity = var(--base-disabled-opacity, 0.65).

-----------------

  --stv-drop-zone-before-bg: rgba(134, 239, 172, 0.25);

  --stv-drop-zone-after-bg-active: rgba(253, 186, 116, 0.85);
  --stv-drop-zone-after-text-color-active: #7c2d12;

BODY CLASS
----------
<Tree bodyClass="my-tree-body" />

Adds a class to the tree body element for scoped styling:

.my-tree-body .stv__node-content {
  padding: 4px 8px;
}

DATA-DRIVEN CLASS HOOKS
-----------------------
Per-row class hooks recompute when a node changes (node._rev):

<Tree
  getNodeClassCallback={({ node }) => node.data?.isArchived ? 'archived' : null}
  getNodeContentClassCallback={({ node }) => node.data?.priority === 'high' ? 'urgent' : null}
/>

getNodeClassCallback applies to .stv__node; getNodeContentClassCallback applies to .stv__node-content.

DARK MODE
---------
Three ways dark mode kicks in:
1. Automatic: --stv-* colors use light-dark() fallbacks, so they follow the
   OS preference (prefers-color-scheme) with no extra config.
2. dark-mode.css also reacts to framework theme classes/attributes
   ([data-theme], [data-bs-theme], .dark) on any ancestor.
3. Per-instance: the theme prop forces one tree dark or light regardless of
   the page. It is forwarded to the root .stv__container as data-theme:

<Tree nodes={data} theme="dark" />
<Tree nodes={data} theme="light" />

Leave theme undefined to inherit from the page.

DARK THEME OVERRIDE EXAMPLE
---------------------------
You can also override the --stv-* tokens for a custom dark palette:

[data-theme="dark"] {
  --stv-text-color-1: #e5e7eb;
  --stv-border-color: #374151;
  --stv-elevated-bg: #1f2937;
  --stv-accent-color: #60a5fa;
}

INDENTATION
-----------
Control node indentation:

:root {
  --stv-indent-size: 1rem;
}

Each level gets this fixed indent.
Level 1 = 0 offset, Level 2 = 1rem, Level 3 = 2rem, etc. (indent is
(level − 1) × per-level).

BEST PRACTICES
--------------
✅ Import styles at app level (once)
✅ Use CSS variables (--stv-* / --base-*) for theming
✅ Use built-in classes when possible
✅ Scope custom styles properly
✅ Use the theme prop for per-instance dark/light

❌ Don't import styles multiple times
❌ Don't override built-in classes globally
❌ Don't use !important unless necessary
❌ Don't forget to test dark mode
