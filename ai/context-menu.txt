CONTEXT MENU
============

CRITICAL: Two approaches for context menus
- Callback-based (recommended): getContextMenuItemsCallback prop
- Snippet-based: ContextMenuItemC / ContextMenuDividerC components inside contextMenu snippet
- Both support dynamic items, icons, keyboard shortcuts, submenus, disabled/hidden states

TYPES (v5.0.0-rc03+)
---------------------
import type { ContextMenuEntry, ContextMenuItem, ContextMenuDivider, ContextMenuContext } from '@keenmate/svelte-treeview';

// rc16: field names follow @keenmate/web-components-core's ActionItem (text / onClick / cssClass)

interface ContextMenuItem {
  id?: string;
  text: string;               // Menu item text (was "label")
  tooltip?: string;
  icon?: string;              // Optional icon (emoji, text, or Font Awesome class)
  shortcut?: string;          // Keyboard shortcut hint (e.g. "Ctrl+C", "F2")
  isDisabled?: boolean;       // Disable the item
  isVisible?: boolean;        // Hide the item (default true)
  isDanger?: boolean;         // Destructive styling
  isToggled?: boolean;        // Toggle item (role=menuitemcheckbox, aria-checked)
  cssClass?: string;          // Extra CSS classes (was "className")
  onClick?: (ctx: ContextMenuContext<T>) => void | Promise<void>;  // Action (was "onclick")
  shouldCloseOnClick?: boolean;   // Default true; false keeps menu open (handler closes via close())
  children?: ContextMenuEntry[];  // Submenu items
}

interface ContextMenuDivider {
  divider: true;              // Discriminator (was "isDivider" in old API)
  text?: string;              // Named divider: ──── [text] ────
}

type ContextMenuEntry = ContextMenuItem | ContextMenuDivider;

CALLBACK-BASED CONTEXT MENU
----------------------------
<script>
  import type { ContextMenuEntry, LTreeNode } from '@keenmate/svelte-treeview';

  function createContextMenu(
    { node, closeMenu: closeMenuCallback, selectedNodes }: { node: LTreeNode<MyItem>; closeMenu: () => void; selectedNodes: LTreeNode<MyItem>[] }): ContextMenuEntry[] {
    return [
      // Basic item with icon and shortcut
      {
        text: 'Open',
        icon: '📂',
        shortcut: 'Enter',
        onClick: () => openItem(node.data)
      },
      // Named divider
      { divider: true, text: 'Edit' },
      // Submenu
      {
        text: 'Move to...',
        icon: '📁',
        children: [
          { text: 'Inbox', onClick: () => moveTo(node, 'inbox') },
          { text: 'Archive', onClick: () => moveTo(node, 'archive') },
        ]
      },
      // Divider
      { divider: true },
      // Danger item
      {
        text: 'Delete',
        icon: '🗑️',
        shortcut: 'Del',
        isDanger: true,
        isDisabled: node.data?.isProtected,
        onClick: () => deleteItem(node.data)
      },
      // Selection-aware item (rc03+)
      ...(selectedNodes && selectedNodes.length > 1 ? [{
        text: `Export ${selectedNodes.length} items`,
        icon: '📤',
        onClick: () => exportItems(selectedNodes)
      }] : [])
    ];
  }
</script>

<Tree
  {data}
  getContextMenuItemsCallback={createContextMenu}
/>

SNIPPET-BASED CONTEXT MENU
---------------------------
<script>
  import { ContextMenuItemC, ContextMenuDividerC } from '@keenmate/svelte-treeview';
</script>

<Tree {data}>
  {#snippet contextMenu(node, closeMenu)}
    <ContextMenuItemC
      text="Open"
      icon="📂"
      shortcut="Enter"
      onClick={() => { openItem(node.data); closeMenu(); }}
    />
    <ContextMenuDividerC text="Edit" />
    <ContextMenuItemC text="Rename" icon="✏️" shortcut="F2" onClick={() => rename(node)} />
    {#if node.data?.canDelete}
      <ContextMenuItemC
        text="Delete"
        icon="🗑️"
        isDanger
        onClick={() => deleteItem(node.data)}
      />
    {/if}
  {/snippet}
</Tree>

SUBMENUS
--------
Nested menus via children array:

{
  text: 'Sort by',
  children: [
    { text: 'Name', onClick: () => sortBy('name') },
    { text: 'Date', onClick: () => sortBy('date') },
    { divider: true },
    { text: 'Ascending', onClick: () => sortDir('asc') },
    { text: 'Descending', onClick: () => sortDir('desc') },
  ]
}

KEYBOARD SHORTCUTS
------------------
When context menu is open, pressing a shortcut key triggers the matching item:

{ text: 'Copy', shortcut: 'Ctrl+C', onClick: () => copyNode() }
{ text: 'Paste', shortcut: 'Ctrl+V', onClick: () => pasteNode() }
{ text: 'Rename', shortcut: 'F2', onClick: () => startRename() }

Supported modifiers: Ctrl, Shift, Alt. Escape closes the menu.

NAMED DIVIDERS
--------------
{ divider: true, text: 'Actions' }    // ──── Actions ────
{ divider: true }                       // ──────────────────

VISIBILITY CONTROL
------------------
Hide items dynamically (callback approach):
{ text: 'Admin Panel', isVisible: user.isAdmin, onClick: () => openAdmin() }

In snippet approach, use {#if}:
{#if user.isAdmin}
  <ContextMenuItemC text="Admin Panel" onClick={() => openAdmin()} />
{/if}

POSITION OFFSET
---------------
<Tree
  getContextMenuItemsCallback={createMenu}
  contextMenuXOffset={8}
  contextMenuYOffset={0}
/>

AUTO-CLOSE BEHAVIOR
-------------------
Context menu automatically closes on:
- Click outside the menu
- Scroll events
- Another right-click
- Pressing Escape
- Window resize

STYLING
-------
CSS classes:
- .stv__context-menu - Menu container
- .stv__context-menu-item - Menu item (modifiers: --disabled, --has-children)
- .stv__context-menu-divider - Divider line
- .stv__context-menu-divider-label - Named divider text
- .stv__context-menu-label - Item label
- .stv__context-menu-shortcut - Shortcut hint
- .stv__context-menu-icon - Item icon
- .stv__context-menu-arrow - Submenu arrow indicator
- .stv__context-submenu - Submenu container

BEST PRACTICES
--------------
✅ Use text (not label), onClick (not onclick), cssClass (not className), { divider: true } (not isDivider)
✅ Use shortcuts for common actions
✅ Group related items with named dividers
✅ Use isDanger: true for destructive actions
✅ Use isVisible to hide items contextually
✅ Use selectedNodes parameter for bulk actions

❌ Don't use old API (title, callback, isDivider) — use new types
❌ Don't create menus with too many items (>10)
❌ Don't forget to handle async onClick errors
