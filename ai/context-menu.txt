CONTEXT MENU
============
Same model as @keenmate/web-treeview (core /actions, vendored in src/lib/vendor/actions).
Two approaches:
- Callback-based (recommended): getContextMenuItemsCallback prop → entries
- Snippet-based: contextMenu snippet with ContextMenuItemC / ContextMenuDividerC components
No menu is shown by default — the menu is whatever the callback returns.

TYPES
-----
import { menuDivider } from '@keenmate/svelte-treeview';
import type { TreeMenuContext, TreeMenuEntry, TreeMenuItem, TreeAction, TreeActionEventDetail } from '@keenmate/svelte-treeview';

// ctx of getContextMenuItemsCallback and of every item get*Callback:
interface TreeMenuContext<T> { node: LTreeNode<T>; path; parent; siblings; controller }

// An entry: an item, a divider, or a built-in action name
type TreeMenuEntry<T> = TreeMenuItem<T> | MenuDivider | TreeAction;

interface TreeMenuItem<T> {        // core MenuItem
  action?: TreeAction | 'custom';  // a built-in (text/state from the tree) — or a string entry
  id?: string;                     // identifies a custom item (reported in onAction)
  text?: string; icon?: string; tooltip?: string; shortcut?: string; cssClass?: string;
  isVisible?: boolean; isDisabled?: boolean; isDanger?: boolean; isToggled?: boolean;
  getTextCallback?(ctx); getIsDisabledCallback?(ctx); getIsVisibleCallback?(ctx); ...  // win over statics
  onClick?(detail: TreeActionEventDetail<T>): void | Promise<void>;
  children?: TreeMenuEntry<T>[];   // submenu (or getChildrenCallback(ctx), may be async)
  shouldCloseOnClick?: boolean;    // default true
}
menuDivider(text?)                 // { divider: true, text? } — named divider: ──── text ────

BUILT-IN ACTION NAMES (texts from `labels`, act on the selection when the clicked node is in it,
else on the clicked node): copy, cut, paste (into the clicked node; disabled with an empty
clipboard), delete (isDanger; runDeleteCommand — beforeDeleteCallback applies), expand, collapse
(one level), expand-subtree, collapse-subtree (targets + descendants), expand-all, collapse-all
(whole tree), sort (children, one level), sort-subtree, sort-all.

ACTIVATION ORDER: beforeActionCallback(detail) (false cancels everything; async OK) → item
onClick(detail) → built-in → onAction(detail). detail = menu ctx + { action, id?, item, source:
'context-menu', sourceEvent?, triggerElement?, dataset }.

CALLBACK-BASED EXAMPLE
----------------------
<script lang="ts">
  import { Tree, menuDivider } from '@keenmate/svelte-treeview';
  import type { TreeMenuContext, TreeMenuEntry } from '@keenmate/svelte-treeview';

  function createContextMenu({ node, controller }: TreeMenuContext<MyItem>): TreeMenuEntry<MyItem>[] {
    const selected = controller.getSelectedNodes();
    return [
      { id: 'open', text: 'Open', icon: '📂', shortcut: 'Enter', onClick: () => openItem(node.data) },
      menuDivider('Edit'),
      'copy', 'cut', 'paste',
      { id: 'rename', text: 'Rename', shortcut: 'F2', isDisabled: !node.data?.canEdit, onClick: () => rename(node) },
      'delete',
      menuDivider(),
      'expand-subtree', 'collapse-subtree',
      ...(selected.length > 1
        ? [{ id: 'export', text: `Export ${selected.length} items`, onClick: () => exportItems(selected) }]
        : [])
    ];
  }
</script>

<Tree
  nodes={data}
  getContextMenuItemsCallback={createContextMenu}
  beforeActionCallback={(d) => d.action !== 'delete' || confirm('Delete?')}
  onAction={(d) => console.log('ran', d.action, d.id, d.path)}
/>

SNIPPET-BASED CONTEXT MENU
---------------------------
<script>
  import { ContextMenuItemC, ContextMenuDividerC } from '@keenmate/svelte-treeview';
</script>

<Tree nodes={data}>
  {#snippet contextMenu(node, closeMenu)}
    <ContextMenuItemC
      text="Open"
      icon="📂"
      shortcut="Enter"
      onClick={() => { openItem(node.data); closeMenu(); }}
    />
    <ContextMenuDividerC text="Edit" />
    <ContextMenuItemC text="Rename" icon="✏️" shortcut="F2" onClick={() => rename(node)} />
    {#if node.data?.canDelete}
      <ContextMenuItemC
        text="Delete"
        icon="🗑️"
        isDanger
        onClick={() => deleteItem(node.data)}
      />
    {/if}
  {/snippet}
</Tree>

SUBMENUS
--------
Nested menus via children array:

{
  text: 'Sort by',
  children: [
    { id: 'by-name', text: 'Name', onClick: () => sortBy('name') },
    { id: 'by-date', text: 'Date', onClick: () => sortBy('date') },
    menuDivider(),
    'sort-all',
  ]
}

KEYBOARD SHORTCUTS
------------------
When context menu is open, pressing a shortcut key triggers the matching item:

{ text: 'Copy', shortcut: 'Ctrl+C', onClick: () => copyNode() }
{ text: 'Paste', shortcut: 'Ctrl+V', onClick: () => pasteNode() }
{ text: 'Rename', shortcut: 'F2', onClick: () => startRename() }

Supported modifiers: Ctrl, Shift, Alt. Escape closes the menu.

NAMED DIVIDERS
--------------
menuDivider('Actions')    // ──── Actions ────
menuDivider()             // ──────────────────

VISIBILITY CONTROL
------------------
Hide items dynamically (callback approach):
{ text: 'Admin Panel', isVisible: user.isAdmin, onClick: () => openAdmin() }

In snippet approach, use {#if}:
{#if user.isAdmin}
  <ContextMenuItemC text="Admin Panel" onClick={() => openAdmin()} />
{/if}

POSITION OFFSET
---------------
<Tree
  getContextMenuItemsCallback={createMenu}
  contextMenuXOffset={8}
  contextMenuYOffset={0}
/>

AUTO-CLOSE BEHAVIOR
-------------------
Context menu automatically closes on:
- Click outside the menu
- Scroll events
- Another right-click
- Pressing Escape
- Window resize

STYLING
-------
CSS classes:
- .stv__context-menu - Menu container
- .stv__context-menu-item - Menu item (modifiers: --disabled, --danger, --toggled, --has-children; data-action / data-id)
- .stv__context-menu-divider - Divider line
- .stv__context-menu-divider-label - Named divider text
- .stv__context-menu-label - Item label
- .stv__context-menu-shortcut - Shortcut hint
- .stv__context-menu-icon - Item icon
- .stv__context-menu-arrow - Submenu arrow indicator
- .stv__context-submenu - Submenu container

BEST PRACTICES
--------------
✅ Use text (not label), onClick (not onclick), cssClass (not className), { divider: true } (not isDivider)
✅ Use shortcuts for common actions
✅ Group related items with named dividers
✅ Use isDanger: true for destructive actions
✅ Use isVisible to hide items contextually
✅ Use ctx.controller.getSelectedNodes() for bulk actions (built-ins already target the selection)
✅ Close a shouldCloseOnClick:false menu with ctx.controller.closeContextMenu()

❌ Don't use the pre-rc16 API (ContextMenuContext with selectedNodes/checkedNodes/closeMenu) — removed
❌ Don't create menus with too many items (>10)
❌ Don't forget to handle async onClick errors
